# Data Boundary

This directory contains redacted records used solely for the bounded examples in
the associated manuscript. The telemetry files retain relative time and power
values needed for numerical-integration audits. The request-outcome files retain
only the fields needed to account for fixed completion-token work and to join
request windows to telemetry.

The records contain no host names, IP addresses, user identifiers, credentials,
model checkpoints, absolute paths, or personal data. They are not externally
calibrated power measurements and do not support claims about whole-server,
facility, carbon, or lifecycle impacts.
